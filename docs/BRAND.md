# 1. PRODUCT CONTEXT

Turtly is a desktop application for managing multiple social accounts in one place.

The product is intended to help the user:

- Store and organize social accounts.
- Quickly find accounts.
- View account status.
- Open the correct account using the correct browser profile.
- Import accounts from CSV / Excel.
- Manage local account information.
- Sync supported metadata.
- Track follower counts and follower history.
- Handle backup and restore.
- Communicate security and sync states clearly.

Turtly is **not**:

- A social media feed.
- A CRM.
- A gaming dashboard.
- A crypto product.
- A hacker-themed password manager.
- A childish turtle app.

The identity should feel like:

> A calm, friendly, well-designed desktop productivity tool that happens to have a memorable turtle mascot.

---

# 2. BRAND IDEA

The turtle represents:

- **Organization** — many accounts contained in one shell.
- **Protection** — sensitive information is handled carefully.
- **Stability** — the app should feel reliable and calm.
- **Persistence** — Turtly is a long-term personal management tool.
- **Portability** — the shell metaphor represents bringing accounts together.

The most important distinctive visual idea is:

> **Tully's shell is built from four rounded account-card tiles.**

This concept must remain recognizable across:

- Logo
- App icon
- Mascot
- Empty states
- Splash screen
- Brand illustrations
- Small shell symbol
- Marketing graphics

The four-tile shell is Turtly's strongest unique brand motif.

---

# 3. BRAND PERSONALITY

Turtly should feel:

### Calm
No visual panic. Errors are clear but not aggressive.

### Organized
Strong hierarchy, clean spacing, structured account cards.

### Trustworthy
Appropriate for an app that handles account information.

### Friendly
Tully softens the product without making it childish.

### Smart
Modern and technically capable without looking futuristic for its own sake.

### Premium
The interface should feel deliberately designed, not like a default admin template.

# 4. LOGO SYSTEM

## 4.1 Primary logo

The primary horizontal logo consists of:

**[Tully turtle mark] + [Turtly wordmark]**

The turtle faces to the right.

The shell contains exactly **four main rounded rectangular panels**.

The mark should visually communicate a turtle first, then reveal the modular/account-card idea on closer inspection.

### Wordmark

Text:

**Turtly**

Style:

- Rounded sans-serif.
- Friendly but mature.
- Thick enough to remain readable.
- Soft geometry.
- Dark teal / forest tone.
- No decorative outline.
- No gradient text.
- No 3D extrusion.

The wordmark should feel visually related to **Nunito Sans ExtraBold / rounded geometric sans**, although the final logo lettering may be customized.

---

## 4.2 Logo visual anatomy

### Turtle body

- Soft mint-green body.
- Rounded head.
- One simple friendly visible eye.
- Small restrained smile.
- Short rounded legs.
- No realistic turtle texture.
- No hard black outlines.

### Shell

The shell is the distinctive element.

It contains:

```text
┌─────────┬─────────┐
│ TILE 01 │ TILE 02 │
├─────────┼─────────┤
│ TILE 03 │ TILE 04 │
└─────────┴─────────┘
```

Actual shapes are softly rounded and follow the perspective of the shell.

Each tile may contain a tiny short horizontal highlight/detail line.

The tiles use nearby teal shades rather than four unrelated colors.

### Shell rim

Use a darker deep-teal shell rim / base to visually contain the four account tiles.

---

## 4.4 Clear space

Always preserve clear space around the logo.

Minimum clear space should visually equal approximately the width of one small shell-panel gap or the height of the lowercase letter `u` in the wordmark.

Never place:

- Borders
- Text
- Other logos
- Platform badges
- Buttons

too close to the Turtly logo.

---

## 4.5 Minimum size

Recommended:

| Asset | Minimum |
|---|---:|
| Full horizontal logo | 96 px width |
| Standalone turtle mark | 32 px |
| Simplified shell mark | 16 px |
| App icon | platform standard |
| Tray mark | optimized 16–32 px version |

At very small sizes:

- Remove tiny eye detail if necessary.
- Reduce shell highlights.
- Preserve the four-panel silhouette.
- Prefer shell mark over the entire turtle if readability is poor.

---

## 4.6 Logo misuse — DO NOT

Never:

- Stretch the turtle.
- Compress the turtle.
- Rotate the logo.
- Skew the shell.
- Recolor shell tiles purple/red/blue randomly.
- Turn each panel into a social-media brand color.
- Add heavy drop shadow.
- Add neon glow.
- Add glossy gaming effects.
- Add crowns, hats, accessories to the official logo.
- Put Tully inside a complicated badge.
- Change the turtle species/style.
- Replace the four tiles with realistic shell scales.
- Add extra shell panels.
- Remove the shell-panel concept.

## 5.2 Suggested extended neutral scale

Use neutral values when required by the product UI, while keeping the brand palette dominant.

Suggested:

```css
--turtly-bg: #F8FAF9;
--turtly-surface: #FFFFFF;
--turtly-border: #E7EBEF;
--turtly-text: #0B2E28;
--turtly-text-secondary: #5F6F6B;
--turtly-text-muted: #899692;
```

These neutrals are implementation helpers, not new brand colors.

---

## 5.3 Semantic status colors

Status colors must serve usability, not branding.

Recommended:

```css
--success: #2E9B64;
--warning: #E3A32B;
--error: #D95C59;
--info: #3B82C4;
--inactive: #8A9691;
```

Every important status must use:

**icon + label + optional color**

Never communicate state using color alone.

---

## 5.4 Color usage hierarchy

### Deep Teal
Use for:

- Major headings
- Brand logo
- Primary high-contrast elements
- Selected states where appropriate

### Green Teal
Use for:

- Primary brand accent
- Buttons
- Interactive emphasis
- Icons
- Active state accents

### Mint
Use for:

- Empty-state illustration backgrounds
- Light Tully body
- Soft badges
- Large calm areas

### Soft Lime
Use sparingly.

Good:

- Tiny active indicator
- Decorative dot
- Small success-like highlight
- Mascot illustration accents

Bad:

- Entire page background
- Large primary buttons everywhere
- Long text

### Platform colors

Facebook / Instagram / other platform colors may appear only in small platform-specific badges/icons.

They must **not override Turtly's brand system**.

Exactly four dominant shell tiles.

### Proportions
Same general head-to-shell relationship.

### Style
Same soft polished illustration quality.

Do not generate each pose in a different art style.

# 12. TULLY USAGE RULES

Use Tully for:

- onboarding
- empty states
- product education
- success
- recoverable errors
- sync/offline explanation
- branded About pages

Do not use Tully:

- on every account card
- beside every button
- inside every toast
- as every functional icon
- in dense data tables
- in every settings row

Recommended density:

> One meaningful Tully moment per screen at most.

For dense screens such as Dashboard, Accounts Grid, and History:

Tully should usually be absent unless the screen is empty or needs contextual explanation.

## 14.3 Shadows

Use restrained shadows.

Example:

```css
--shadow-card:
  0 1px 2px rgba(11, 46, 40, 0.04),
```

Do not use:

- dramatic black shadows
- colored glow
- neon shadows

Borders should carry more structural weight than shadows.
